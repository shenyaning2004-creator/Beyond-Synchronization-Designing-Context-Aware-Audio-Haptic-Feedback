# Beyond Synchronization: Designing Context-Aware Audio-Haptic Feedback

本仓库收录实验所用的音触协同（Audio-Haptic）测试音频，涵盖**放松、助眠、唤醒**三个场景，包括纯音乐、白噪音、人声音乐等多种音频类型。
