# Beyond Synchronization: Designing Context-Aware Audio-Haptic Feedback

This repository contains the test audio used in our audio-haptic experiments. The collection covers three scenarios—**relaxation, sleep onset, and awakening**—and includes instrumental music, white noise, vocal music, and other audio types.

## Scenarios and Directories

| Scenario | Directory | Number of Tracks |
| --- | --- | --- |
| Relaxation | [Pre-sleep Relaxation](./Pre-sleep%20Relaxation/) | 6 |
| Sleep Onset | [Sleep Onset](./Sleep%20Onset/) | 6 |
| Awakening | [Awakening](./Awakening/) | 6 |

The collection contains 18 WAV audio files, organized by scenario for use in audio-haptic experimental testing.
